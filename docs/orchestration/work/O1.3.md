# O1.3 — Claude Code real controlado

**Autorizó:** Juan, por fases, en la conversación de Claude Code. **Fechas:** 2026-11-01 y 2026-11-02.

Este bloque se dirige a mano. Esta especificación cubrió **O1.3.2** y ahora cubre **O1.3.5**; las demás fases
necesitan su propio gate.

| Fase | Estado |
|---|---|
| O1.3.1 Contrato | Hecho en desechable, ver resultados |
| O1.3.2 Ejecutor real en el runner y pruebas de procesos | Integrado (PR #62) |
| O1.3.3 Pruebas negativas | Hecho en desechable, ver resultados |
| O1.3.4 Consola acotada con hijo y nieto | Hecho en desechable: **la consola no se puede acotar**, ver [resultados](../resultados-o1-3-4.md) |

| Cierre de O1.3 | Pendiente |

## Objetivo

Que el runner pueda lanzar Claude Code real con las protecciones ya demostradas, sin consola y solo para
documentación, y que todo lo que haga se verifique por separado, también cuando se detiene.

## Dentro del alcance

O1.3.2, ya integrado:

1. `ClaudeExecutor` en el runner: versión exacta, comparación exacta del primer evento, opciones fijas,
   `--settings` prohibido, reglas `Edit(ruta)`, denegación de `.env`, entorno cerrado.
2. `GIT_TRACE` con lista cerrada de comandos Git, y validador de `structured_output`.
3. Rutas siempre prohibidas: `docs/adr/**` y `**/.credentials.json`.
4. Perfil `code` prohibido con ejecutor real, y repositorio real rechazado.
5. Claude falso y tests que corren en CI; tests reales que solo corren a mano.
6. Pruebas reales de timeout, Ctrl+C, muerte del runner y Claude esperando, en desechable.
7. ADR 0037 y resultados de O1.3.1 y O1.3.3.

O1.3.5, en este PR:

1. Sin consola como invariante técnica: lista propia de herramientas de archivos, comprobada al importar, al
   construir el comando y en el primer evento; el prefijo de los tests no puede llevar opciones.
2. Revisión de daños en cualquier salida del ejecutor real, incluidos Ctrl+C y un error al leer el log,
   conservando el motivo de la parada.
3. Configuración de Claude Code de usuario, proyecto y administrada, por defecto denegada.
4. Resultados de O1.3.4 y actualización del ADR 0037.

## Fuera del alcance

- Consola para Claude, de cualquier forma. Ya no es una fase pendiente: el ADR 0037, §4, la descarta.
- `O1.3.R1`, cualquier `run` sobre el repositorio real, y O1.4.
- Exponer el ejecutor real en la consola del runner o en `Start-ElsaBlock.ps1`.
- Corregir las 3 pruebas de Windows y los 3 errores de `mypy`: bloque aparte.
- `src/elsa`, Render, Supabase, SAP, migraciones y CI.

## Decisiones

| Decisión | Motivo |
|---|---|
| El ejecutor real no aparece en la consola | No hay ningún uso autorizado sobre el repositorio real todavía |
| Claude queda esperando mediante un proxy local que no responde | Da un estado real de espera sin darle capacidades. **Inferencia:** la autenticación no viaja, porque el TLS no se establece; el proxy no lee nada |
| Sin archivo de settings | Un archivo inválido se ignora en silencio |
| El trazado desconocido de Git también detiene | Lo prohibido por defecto |
| Claude real sin consola, sin excepciones | En O1.3.4, `Bash(<comando exacto>)` dejó pasar otros comandos y encadenarlos |
| La configuración administrada se niega sin leerla | Se aplica aunque `--safe-mode` y `--restricted` desactiven lo demás, y su contenido no se puede validar con certeza |

## Criterios de aceptación

| Acción | Resultado esperado |
|---|---|
| Capacidad inesperada en el primer evento | El proceso se termina y el bloque se detiene |
| Versión distinta, antes o después | El bloque se detiene |
| Comando Git no observado | El bloque se detiene |
| `structured_output` inválido o distinto de Git | El bloque se detiene |
| Consola en `--tools`, `--allowedTools`, el primer evento o la constante | El bloque se detiene, o el runner no importa |
| Cualquier parada, Ctrl+C o error con un daño previo | Gana el daño; el informe conserva el motivo de la parada |
| Configuración de proyecto, MCP o administrada | El bloque se detiene antes de lanzar |
| Cambio documental real en desechable | `verified_local` |
| Timeout, Claude esperando, Ctrl+C y muerte del runner | Sin procesos vivos |
| Repositorio real | Idéntico antes y después |
| Suite, ruff, mypy, pre-commit, `git diff --check`, revisión de seguridad | En verde |
| PR creado por Juan | CI en verde; sin merge por Claude |
